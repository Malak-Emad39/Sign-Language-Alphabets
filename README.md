# Sign-Language-Alphabets

## Overview
This project focuses on image preprocessing techniques used in Computer Vision and Machine Learning tasks.  
The preprocessing pipeline improves image quality and prepares the dataset for better model performance.

## Features
- Convert RGB images to Grayscale
- Resize images to a fixed size
- Apply CLAHE enhancement for better contrast
- Normalize pixel values
- Visualize Original vs Preprocessed images

## Technologies Used
- Python
- OpenCV
- NumPy
- Matplotlib
- Scikit-image

## Preprocessing Steps
1. Read image dataset
2. Convert image to grayscale
3. Resize image
4. Apply CLAHE enhancement
5. Normalize image pixels
6. Display processed results
